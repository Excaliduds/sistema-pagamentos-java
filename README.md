# Sistema de Pagamentos

Projeto desenvolvido em Java para simular diferentes formas de pagamento utilizando conceitos de Programação Orientada a Objetos.

## Funcionalidades

- Pagamento via boleto
- Pagamento via cartão
- Pagamento via cripto
- Pagamento via PIX
- Processamento de pagamentos
- Validação de dados

## Conceitos aplicados

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces

## Tecnologias

- Java
- Eclipse IDE
